지금 임시로 채팅 기능을 Chat.tsx에 만들어놨는데 그걸 처음부터 다시 재설계를 할거야. 
일단 주요 기능을 알려줄게:
- AI가 Story 오브젝트를 편집할 수 있는 기능
AI는 각각 <init>, <add>, <edit>, <delete> xml태그를 이용해서 story object를 편집 가능.
사용 예:
맨 처음 story object 초기화(덮어쓰기)
<init>
```json
{
    "basic_info": {
        "title": "string",
        "logline": "string",
        "genre": "string"
    },
    "characters": [{
        "name": "string",
        "description": "string"
    }],
    "organizations": [{
        "name": "string",
        "description": "string"
    }],
    "locations": [{
        "name": "string",
        "description": "string"
    }],
    "outline": {
        "acts": [{
            "name": "string",
            "description": "string"
            "chapters": [{
                "name": "string",
                "description": "string"
            }]
        }]
    }
}
```
</init>

주의사항: init은 반드시 이 형식을 따라야함.

특정 오브젝트 추가 예시:

```json

        "description": "string"
```

</add>

<add>
```json

        "name": "string",
        "description": "string"
        "chapters": [{
            "name": "string",
            "description": "string"
        }]
    }]

```
</add>
액트 안에 챕터만 추가시:
<add>
```json

    "chapters": [{
        "act_id": "string",

        "description": "string"
    }]

```
/<add>

특정 오브젝트 수정 예시:
<edit>
```json
{
    "basic_info":{
        "title": "string",
        "logline": "string",

```
</edit>

특정 오브젝트 삭제 예시:
<remove>
```json
[{
    "id": "string"
}]
```
</remove>

그리고 이런 태그는 후술할 display-processing을 통해 카드형태로 변환해서 유저에게 그 수정을 apply할지 물어본다음 그걸 적용을 하는거야.

{유저의 요청사항}

---
이런식으로 유저가 새로운 요청을 보내면 나갈거야. 그리고 이 기능을 켰다 끌수 있도록 입력창 위에 체크표시로 넣을수 있게 하자.

그리고 이런 작업을 위해 채팅내용을 처리하는 파이프라인을 처리할거야. 일단 크게 3가지로 나뉘어, 하나의 truth source인 ChatMessage를 기반으로 pre-processing, post-processing, display-processing, 이렇게 3가지로 나뉘어서 작업을 할거야.

Pre-processing:
ChatMessage를 AI로 보내기 위한 형식으로 변환하는 과정.
System role로 system 프롬프트 맨 앞에 추가하기, 유저의 마지막 챗에 <system> 태그 달아주기.
AI가 작업한 편집 태그 안에 있는 내용 간략화 하기:
예시
<init>
[Summerized by system: You added 10 characters]
</init>

Post-processing:
AI의 출력 결과물을 영구적으로 변환하는 과정.
아직까지 구현할 기능은 없음. 파이프라인만 생성.

Display-processing:
ChatMessage를 유저를 위해 Display로 표시하는 과정.
편집 태그를 카드로 변환,
Markdown처리 등을 수행

다음과 같은 파이프라인을 기반으로 아예 처음부터 코드를 다시 설계한다는 느낌으로 할거니깐. 작업좀 해줘.
일단 파이프라인을 만드는거 부터 시작하자.
